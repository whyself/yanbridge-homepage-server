# Audit Existing Pool Workflow

Use this when checking whether an existing pool or clean file follows the skill.

## 1. Identify Scope

Determine which files exist:

- `*_faculty_urls.md`
- `*_lab_urls.md`
- `*_clean_faculty_urls.md`
- `*_clean_lab_urls.md`
- `*_root_urls.md`
- clean decision ledgers or Crawl4AI packet directories

## 2. Choose Checklist

- Detail/pool audit -> read `checklists/detail-review.md`.
- Crawl4AI clean audit -> read `checklists/crawl4ai-clean.md`.
- Final delivery audit -> read `checklists/final-report.md`.

## 3. Sample Risky Items First

Prioritize known high-risk patterns:

- generic admissions/training pages;
- news, PDFs, ZIPs, datasets, tools, downloads;
- personal homepage team/member tabs;
- joint-lab/platform/collaboration anchors under a parent lab;
- script-generated candidate lists or clean decisions;
- clean entries not backed by full page-read evidence.

## 4. Record Corrections

Edit clean files only after identifying the reason. Put reasons in root/ledger, not in clean files. Keep clean files as names plus URLs only.
