# Checklist Index

This compatibility file replaces the old all-in-one checklist. Do not load every gate by default. Read only the checklist needed for the current route.

## Route

- Detail-read closure, reverse search, pool file hygiene: read `../checklists/detail-review.md`.
- Serial Crawl4AI lab/faculty cleaning: read `../checklists/crawl4ai-clean.md`.
- Final response counts and completion claims: read `../checklists/final-report.md`.

## Shared Gates

- A visible todo existed before collection/crawling/file edits and was updated as phases completed.
- Final pool and clean Markdown files use plain blocks only: name line, raw HTTP/HTTPS URL lines, blank line between entries.
- Final pool and clean Markdown files contain no bullets, nested lists, numbering, tables, Markdown links, notes, statuses, or evidence.
- Notes, failures, ambiguity, rejected URLs, Crawl4AI decisions, and pending work live in the root/ledger file.
- No completion claim is allowed unless the route-specific checklist and `../checklists/final-report.md` are satisfied or the missing gates are explicitly reported.
