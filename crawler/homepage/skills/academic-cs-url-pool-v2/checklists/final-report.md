# Final Report Checklist

Clean files contain only names plus HTTP/HTTPS URLs:

- `faculty_urls.md`
- `lab_urls.md`
- `clean_faculty_urls.md`
- `clean_lab_urls.md`

Process notes, failures, fallback notes, and status markers are only in root/ledger files.

Report:

- faculty entry count;
- faculty URL count;
- lab/group entry count;
- lab/group URL count;
- clean faculty entry count;
- clean faculty URL count;
- clean lab/group entry count;
- clean lab/group URL count;
- removed empty/low-value faculty URL count;
- lab admissions pages found count;
- failed/pending/abnormal count;
- whether full detail-page closure completed;
- whether reverse search completed for every final name;
- whether serial Crawl4AI lab clean completed;
- whether serial Crawl4AI faculty clean completed;
- important limitations or pending review categories.
