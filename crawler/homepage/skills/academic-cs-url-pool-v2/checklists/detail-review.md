# Detail Review Checklist

- Todo was written before collection work.
- Scope, output directory, canonical English filename stem, and likely domains are clear.
- Keyword coverage includes broad CS and university-specific units in Chinese and English.
- Root URLs were confirmed by opened/fetched page content, not snippets.
- Native web open/fetch detail review followed full-page reading: content-first judgment, not script/link extraction.
- Every final faculty/lab URL was opened/fetched, read, classified, and checked for useful links.
- Personal-homepage team/member tabs were not classified as lab/group homepages unless independently identified as lab/research group/课题组/实验室.
- Every useful or maybe useful discovered link was opened/fetched, read, classified, and recursively analyzed.
- Scripts, regexes, URL paths, anchor text, keyword hits, generated summaries, and precomputed classifications were not substitutes for full-page reading.
- Subagent batches reported full-page read status, newly discovered links, recursive checks, and failures.
- Placeholder, JS-shell, blank, generic-template, and redirect-shell reads were rendered by the main agent or recorded as `pending_render_check`.
- Every final faculty/advisor name and lab/group/team/center name has a reverse-search status.
- No `reverse_added` item lacks detail-read evidence.
